# 福彩3D 选5胆码

每天预测下期福彩3D开奖的 **5 个胆码**（0-9 中选 5 个数字）。
命中判定：**下期开奖的百/十/个 3 个数字中，至少有 1 个出现在 5 胆内**即算命中（5胆命中）。

- 随机基线：5 胆命中 = 1 − C(5,3)/C(10,3) = **91.67%**
- 单码胆中基线：某个具体数字出现在开奖 3 码中 = 1 − (9/10)³ = **27.1%**
- ⚠️ 5 胆命中基线已高达 91.67%，可提升空间有限。本软件在最新 200 期上从 905 万公式穷举选最优 5 胆组，
  属历史拟合，**样本外大概率回落到基线附近**，仅供研究参考，不构成投注建议。

## 每日预测跟踪

- 预测在**开奖前**落盘到 `data/predictions.jsonl`（期号 + 5胆 + 预测时间），杜绝事后编造
- 下次运行自动用已开奖数据**回填结果**（draw/hit），同 issue 幂等不重复
- 页面「📅 每日预测跟踪」区块展示累计真实命中率（唯一样本外指标）+ 近30期明细
- 与回测表（905万公式窗口内拟合，会虚高）严格区分：跟踪表才是真实水平

## 云端全自动（GitHub Actions）

- 三重 cron（北京时间 22:00 / 23:30 / 01:00，21:30 开奖后执行，3 次机会兜底），concurrency 防撞车
- 多源降级抓取（huiniao / 17500 / apihz / cwl / 55128 / 8200，urllib 无第三方依赖），
  新期号自动追加 CSV（不覆盖历史，只收 > 本地最新期号的数据防倒灌）
- 幂等：数据与 5 胆组均无变化时不重写页面（含时间戳），workflow 以 CSV/公式/页面三方 git diff 判断，
  无变化跳过提交与部署
- 依赖：`pip install "numpy>=1.26,<3"`（锁版本）
- 页面 `updated` 用北京时间

## 算法

1. **特征引擎**：59 个特征（上期单期 34 + 单期派生 9 + 跨期 16），第 i 期预测只用第 i-1/i-2 期数据，不偷看未来
2. **公式池**：`(c1×特征A + c2×特征B [+ c3×特征C] + 常数) mod 10`，单/双/三特征 ≈ 905 万条
3. **选胆策略**：
   - Top-50 公式单码榜（单码胆中 = 输出 v ∈ 当期开奖3码）
   - 按数字归并（每组保留命中率最高者）
   - 5 胆组合：方案A 贪心取前5 / 方案B 穷举 C(30,5) 取组命中率最高
4. **回测**：固定 5 胆组逐期真实预测（近期→远期），5胆命中率 + 最大连错

## 风险与诚实声明

- 905 万公式在 200 期上穷举选最优 = **过拟合**：窗口内命中率必然高于样本外真实水平
- 参考已验证数据（杀一码同框架样本外测算）：窗口内 99% 的公式样本外 3 杀全中仅 ~72.7% ≈ 随机基线 72.9%；
  胆码同理，样本外大概率回落到基线 91.67% 附近
- **仅供研究参考 · 不构成投注建议 · 历史拟合样本外会回落**
